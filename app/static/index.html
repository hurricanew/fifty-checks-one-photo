One photo, one API call

50 checks on one photo

Upload one phone photo of a server rack. Replay mode shows a fixed sample so you can see the tiles without a key. Live mode sends that photo once to Gemini Decision 1 and asks fifty yes/no questions in the same call. Green means the check looks good, red means it looks bad, amber means a person should look.

Replay loads a fixed file labelled SAMPLE - not a real API result. It does not call the API, it does not score your photo, and it has no measured latency, tokens, or cost.

Tile colors are a reading of P(yes) and confidence against the cut-offs on this page. They are not a measured accuracy score.
